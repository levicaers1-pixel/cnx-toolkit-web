Privacyverklaring

English: PRIVACY.md.

Deze verklaring beschrijft wat de webapp van de CNX Toolkit met gegevens doet. Ze geldt voor de gehoste versie (cnx web --server, bijvoorbeeld op Azure) en voor de lokale app op je eigen pc. Wie een exemplaar van de toolkit draait, is verantwoordelijk voor dat exemplaar; de toolkit zelf is zo gebouwd dat de server niets bewaart.

Kort

  • Geen account, geen database, niets bewaard op de server. De server houdt gegevens enkel in het geheugen, zolang hij ze nodig heeft, en schrijft niets op schijf.
  • Geen analytics, geen trackers, geen reclame. De pagina laadt niets van andere sites.
  • Je Central-gegevens (API-URL, client-ID, secret) staan enkel in het geheugen van je sessie en verdwijnen bij afmelden, na 30 minuten zonder activiteit, of als de server herstart.

De logs bevatten geen IP-adressen, geen parameters (zoals device groups, serienummers of tokens) en geen inhoud.

Cookies

Cookie Waarvoor Hoe lang
cnx_sessie Koppelt je browser aan je sessie op de server (HttpOnly, Secure, SameSite=Strict) Tot je de browser sluit; de sessie zelf stopt na 30 minuten zonder activiteit
cnx_taal Je taalkeuze (NL of EN) 1 jaar

Beide zijn strikt nodig om de app te laten werken; er zijn geen andere cookies.

Wie gegevens krijgt

  • HPE (je eigen new Central en HPE GreenLake): de toolkit stuurt je client-ID en secret naar de aanmeldservice van HPE en roept daarna, in jouw naam, de API aan van de Central die je opgaf. Die gegevens blijven in je eigen HPE-omgeving.
  • De hostingprovider (voor het publieke exemplaar op cnx.caersultancy.com: Microsoft Azure Container Apps, regio North Europe) draait de server en het netwerk. Azure houdt technische platformcijfers bij, zoals het aantal aanvragen en het CPU-gebruik. Log Analytics staat niet aan.
  • Niemand anders. De server stuurt niets naar andere partijen.

Wat je zelf kan doen

  • Meld af (rechtsboven) om je gegevens meteen van de server te halen.
  • Klik op Vergeten in het tabblad AP-migratie om de inventaris en voortgang van een klant te wissen, of wis de sitegegevens in je browser om alle bewaarde AP-migratie en voorkeuren te verwijderen. Exporteer eerst een migratiebestand als je het nog nodig hebt.
  • Gebruik voor de toolkit een aparte API-client van Central, met enkel de rechten die nodig zijn, en trek hem in als je klaar bent. De server bewaart het secret nooit, maar wie een exemplaar draait, kan in principe het geheugen van de eigen server lezen. Gebruik enkel een exemplaar dat je vertrouwt, of draai de toolkit zelf.
